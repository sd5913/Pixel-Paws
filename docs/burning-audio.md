# Burning audio

`src/assets/audio/ui/fire-crackle/burning.wav` is an original deterministic four-second mono PCM loop generated by `src/assets/generators/generate-fire-crackle.mjs`. It combines low-level filtered noise with irregular short crackles and has soft loop-edge fades. No third-party recording is used.

Third-room active burning props drive one shared looping voice. Its base gain starts at 0.195 for one fire and increases logarithmically to a maximum of 0.30 before the user's effects-volume slider. Voice gain changes are smoothed in real Web Audio. The loop stops on no active fire, pause/results, restart, hidden document, mute, disabled effects and disposal; resuming active gameplay restarts it as needed. Multiple fires do not create overlapping loop voices. Background fireplace scenery alone does not trigger this new sound.

Validation: audio-manager lifecycle tests cover single-voice reuse, bounded volume, effects preferences, mute, stopping and disposal. Chrome verifies that an ignited prop starts the decoded looping buffer and reset stops it without page errors. Real-device listening remains for review. Teammate review is required before merging to main.
